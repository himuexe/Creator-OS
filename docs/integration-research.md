# Integration research

Reviewed on 23 November 2026 for the personal CreatorOS workspace. Release dates below identify the upstream material inspected. Local execution results belong in the development log.

## FFmpeg and FFprobe

Use the two command-line executables as the media boundary. FFprobe can return JSON with container and stream information through `-show_format -show_streams -of json`. Select the video stream explicitly, parse its rational frame rate, and count audio streams separately. Treat an absent duration or an invalid denominator as an unknown value. FFmpeg's release page lists version 9.1 dated 20 November 2026 and provides Linux, Windows and macOS distribution options. This release is evidence of upstream maintenance. The operations above also exist in earlier builds. [FFprobe manual](https://ffmpeg.org/ffprobe.html) · [FFmpeg releases and binaries](https://ffmpeg.org/download.html)

For production jobs, map a validated operation to a fixed argument list and a private job directory. Limit input protocols, formats, runtime and concurrency. CPU processing is sufficient for probing and basic software encoding. Encoder, decoder and filter availability depends on the installed build. Before enabling subtitle rendering and vertical export, check the chosen build for the required encoder, scaler and subtitle filter, then probe and decode a synthetic output. Size scratch storage for the source, intermediates and output. [FFmpeg CLI](https://ffmpeg.org/ffmpeg.html) · [Protocol options](https://ffmpeg.org/ffmpeg-protocols.html) · [Filter reference](https://ffmpeg.org/ffmpeg-filters.html)

Upstream FFmpeg uses LGPL-2.1-or-later as its base license. Optional GPL components change the applicable license of the built executable. Record the exact package, configuration, notices and matching source before redistributing an image containing FFmpeg. Codec patent considerations depend on the distribution and jurisdiction. [FFmpeg license and legal considerations](https://ffmpeg.org/legal.html)

## FFmpeg Skill

Version 4.7.0 shipped on 22 November 2026. The project exposes local Python tools through a versioned contract and an optional MCP server. The setup command needs Node 16+ and Python 3.10+. Media operations need FFmpeg, FFprobe and the specific codecs or filters used by the operation. Optional transcription additionally needs a speech engine and model. The repository uses the MIT license. [Release](https://github.com/kajisho5/ffmpeg-skill/releases/tag/v4.7.0) · [Requirements and capabilities](https://github.com/kajisho5/ffmpeg-skill) · [License](https://github.com/kajisho5/ffmpeg-skill/blob/main/LICENSE)

CreatorOS can use three design patterns directly in its own code. Validate operation inputs through a schema, check executable capabilities per operation, and record the output properties needed to verify success. For example, a vertical render needs media inspection after encoding to verify dimensions, duration and expected streams. Keep the source immutable and give each generated version its own storage key. This project serves as a design reference only. [Execution contract](https://github.com/kajisho5/ffmpeg-skill/blob/main/docs/contract.md)

## Postiz

The release page returned v2.26.0, published 13 November 2026. For Milestone 6, use a separately configured Postiz deployment through its public v1 HTTP API. A single workspace can use an organization API key in the `Authorization` header. Postiz also documents OAuth for applications acting for other users. The self-host instructions list PostgreSQL 14+, Redis 6+, Temporal and persistent media storage. The documented light-use floor is 2 vCPU, 2 GB RAM and 20 GB of disk. This footprint belongs to the optional publishing deployment. [Release](https://github.com/gitroomhq/postiz-app/releases/tag/v2.26.0) · [Authentication](https://docs.postiz.com/public-api/introduction) · [Self-host requirements](https://docs.postiz.com/self-host/installation/system-requirements)

For an authorized publishing account, list connected integrations and fetch that channel's posting rules. Examples include YouTube, TikTok, Instagram and LinkedIn. Use multipart `POST /upload` to obtain the remote attachment ID and path. Record the creator's approval of an asset version, destination, metadata and schedule before sending the publish request. `POST /posts` accepts a draft or scheduled post and provider-specific settings. Store returned post identifiers. Reconcile ambiguous responses before retrying to avoid publishing the same asset twice. Postiz offers publication webhooks and a test delivery. Check the payload of the actual deployment and deduplicate callbacks. [Channels and settings](https://docs.postiz.com/public-api/integrations/settings) · [Channel connection](https://docs.postiz.com/public-api/integrations/connect) · [Upload](https://docs.postiz.com/public-api/uploads/upload-file) · [Create post](https://docs.postiz.com/public-api/posts/create) · [Webhooks](https://docs.postiz.com/general/automations/webhooks)

Postiz publishes its application under AGPL-3.0. Redistribution carries license and corresponding-source obligations. Section 13 also requires an offer of corresponding source to remote users of a modified version. Keep CreatorOS's independent HTTP client and the Postiz deployment separately identifiable. Review the actual packaging and any modifications before commercial distribution. The foundation has no Postiz credentials, publishing service or external account connection. [Postiz license](https://github.com/gitroomhq/postiz-app/blob/main/LICENSE)

## VoiceStudio

The release page returned v0.5.8, published 12 November 2026. Upstream documents a local speech server, voice design and cloning, video dubbing and several speech engines. OmniVoice supports CPU, CUDA and Apple MPS. The catalog also includes CPU-only preset voices through KittenTTS. Dependencies, model download size and practical throughput vary by engine. Source development uses Python and Bun, with desktop builds and container images also available. Benchmark a candidate engine on representative narration before choosing it. [Release](https://github.com/debpalash/VoiceStudio/releases/tag/v0.5.8) · [Installation options](https://github.com/debpalash/VoiceStudio) · [Engine catalog](https://github.com/debpalash/VoiceStudio/blob/main/docs/engines/README.md)

For optional Milestone 4 narration, a provider can submit script text, a voice ID and an installed model ID to the documented `POST /v1/audio/speech` endpoint. A remote deployment supports a bearer credential. Keep credentials server-side. Store the audio with the source scene, provider, model and voice IDs. Begin with a licensed preset voice. A voice clone would require explicit permission from its owner. [Speech API](https://github.com/debpalash/VoiceStudio/blob/main/docs/agentic-voice.md) · [Authentication](https://github.com/debpalash/VoiceStudio/blob/main/docs/api-auth.md)

The application license notice specifies AGPL-3.0-only and explains source obligations for modified network deployments. Model weights and voices have separate terms. The maintainers identify the default OmniVoice weights as noncommercial. Review the specific engine, weights and voice rights for the intended output, particularly for monetized material. No VoiceStudio code or weights are required for the foundation. [License notice](https://github.com/debpalash/VoiceStudio/blob/main/LICENSE-NOTICE.md) · [Upstream model licensing summary](https://github.com/debpalash/VoiceStudio#license--responsible-use)
